# Posterior means (natural scale)

Posterior means (natural scale)

## Usage

``` r
posterior_means(fit)
```

## Arguments

- fit:

  A Bayesian \`"compartmentalFit"\` object.

## Value

A named numeric vector of posterior means.

## Examples

``` r
if (FALSE) { # \dontrun{
posterior_means(fit_b)   # fit_b a method = "bayes" fit
} # }
```
