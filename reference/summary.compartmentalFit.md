# Summary of a compartmental fit

Summary of a compartmental fit

## Usage

``` r
# S3 method for class 'compartmentalFit'
summary(object, ...)
```

## Arguments

- object:

  A \`"compartmentalFit"\` object.

- ...:

  Unused.

## Value

\`object\`, invisibly (called for the printed summary).

``` r
if (FALSE) { # \dontrun{
```
